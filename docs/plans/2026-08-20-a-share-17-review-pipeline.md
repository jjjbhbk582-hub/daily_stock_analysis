# 17只A股收盘复盘流水线实施计划

## 目标

在每个沪深A股交易日收盘后，对固定17只股票生成可复现的完整复盘数据、100分综合评分、17只排名、Top5交易条件与上次结果对比。任何单一数据源失败都不得导致整份报告停工，也不得以前一交易日数据冒充当日数据。

## 架构

1. `src/a_share_review/universe.py`
   - 固定17只股票、所属主题与基础行业映射。
   - 集中管理评分评级区间。
2. `src/a_share_review/providers.py`
   - 日历：`exchange_calendars`，AKShare交易日历作为可选交叉验证。
   - 批量收盘快照：AKShare/东方财富为主，腾讯行情为兜底。
   - 日线：AKShare东财为主、腾讯历史日线为兜底；若历史接口尚未落地当日K线，用15:00后的已验证收盘快照补成当日完成日线。
   - 60分钟：AKShare分钟线；失败时只降低60分钟分项并显式标记，继续完成其余股票。
3. `src/a_share_review/indicators.py`
   - 自行计算 MA5/10/20/50/100/200、EMA5/10/20/50、RSI14、MACD、KDJ、Stoch RSI、ADX、OBV、近20日高低点和相对20日均量。
   - 识别放量突破、缩量回踩、假突破、跌破后反抽及基础背离。
4. `src/a_share_review/scoring.py`
   - 严格按30/20/25/15/10五大分项计分。
   - 数据缺失只影响对应分项并产生质量标记，不以单日大涨或超卖直接加高分。
5. `src/a_share_review/levels.py`
   - 基于结构位、均线、20日高低点和ATR生成回踩区、突破触发价、不追涨区、失效价、两档目标位和风险收益比。
6. `src/a_share_review/report.py`
   - 输出用户要求的五部分Markdown与最终三类操作结论。
   - 保存结构化JSON供次日比较。
7. `src/a_share_review/pipeline.py`
   - 交易日/收盘状态检查、逐股容错、跨源校验、历史快照读取、报告与JSON持久化。
8. `.github/workflows/a-share-17-review.yml`
   - 工作日北京时间15:30（UTC 07:30）执行，支持手动触发。
   - 先运行专用测试，再生成报告；保存Artifacts，并将当日JSON/Markdown提交回专用数据分支或当前分支。

## 测试顺序

1. 指标计算与无未来函数测试。
2. 当日历史K线未落地时，用已验证收盘快照补齐的测试。
3. 单只/单源失败不阻断其余股票的测试。
4. 休市与未收盘拒绝运行测试。
5. 评分上限、评级映射、Top5排序与价格区间逻辑测试。
6. 前后两日排名、评分、趋势和买点变化比较测试。
7. Markdown固定结构和17行完整排名测试。

## 验收标准

- 固定股票池恰好17只。
- 正常样例输出17只排名与5只Top5。
- 当日完成日线日期必须等于目标交易日；否则该股票标记失败，不能伪装成功。
- 一个数据源或一只股票失败时，其余股票仍输出。
- 所有技术指标由原始K线本地计算。
- 每个价格字段带数据日期和来源元数据。
- 报告与结构化快照可重复运行且结果确定。
- 离线单元测试全部通过，网络烟雾测试独立标记。
