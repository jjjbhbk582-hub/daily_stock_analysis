# 板块全景排名与2+2动态候选设计

## 背景

现有收盘复盘引擎能够完成固定17只沪深A股的日线、周线、60分钟结构、100分评分、Top5买点和历史比较，但板块层目前只有行业涨跌摘要与固定股票池主题代理。短线交易需要先判断资金正在攻击或撤离哪个板块，再在强板块中选择不同角色的股票。

本设计增加独立的板块层，不把固定17只样本冒充全市场概念板块，也不把每天生成的动态候选永久写入固定股票池。

## 目标

1. 每个交易日收盘后生成行业板块完整排名和概念板块排名。
2. 计算板块当日涨幅、5日和20日趋势、成交额与相对20日量能、上涨/下跌家数、涨停数和100分板块评分。
3. 选择综合评分最高的5个板块，以及相对上一交易日排名提升最快的2个板块；去重后最多详细分析7个板块。
4. 每个详细板块选择两只龙头和两只高潜力股票：资金容量龙头、弹性龙头、缩量回踩潜力股、放量突破潜力股。
5. 保留AI算力、CPO、PCB、半导体、存储芯片、稀土、人形机器人、创新药、液冷服务器、消费电子、军工和有色金属等重点概念的每日简表。
6. 将板块结果写入结构化快照、历史状态和Markdown报告，并与上一交易日比较。

## 非目标

- 不自动下单，不承诺收益。
- 不把动态候选自动加入固定17只股票池。
- 不为了凑齐2+2选择不符合硬过滤条件的股票。
- 不使用未完成日线或前一交易日行情冒充目标日行情。

## 全局硬约束

动态板块候选必须同时满足：

- 仅沪市主板和深市主板普通A股；允许代码前缀为`600`、`601`、`603`、`605`、`000`、`001`、`002`、`003`。
- 目标交易日有效收盘价大于0且不高于100.00元。
- 名称不含`ST`、`*ST`、`退`，不属于ETF、指数、B股、创业板、科创板或北交所。
- 当日成交额不少于3亿元，成交量大于0。
- 排除停牌和一字涨停/一字跌停；当日最高价等于最低价且绝对涨跌幅不低于9.5%时视为不可正常成交。
- 候选必须具备目标日完成日线；需要精确买点时还必须通过现有行情置信度门槛。

阈值写入`close_review_engine/config/sector_monitor.yml`，后续可配置，但默认值不得放宽上述价格、市场和ST限制。

## 数据架构

### 行业板块

优先使用东方财富行业板块列表、历史K线和板块成份接口。列表返回当日涨幅、换手率、上涨/下跌家数和领涨股；历史K线用于计算5日/20日收益与相对20日成交额；成份接口用于2+2候选筛选。

若行业板块列表不可用，允许使用已完整验证的全市场股票快照按行业聚合生成当日行业涨幅、成交额和广度。降级结果必须标记`partial`，不得伪造5日/20日板块历史。

### 概念板块

优先使用东方财富概念板块列表、历史K线和板块成份接口。概念接口失败时，只保留固定重点概念的“数据暂缺”状态，不使用固定17只主题代理冒充全市场概念表现。

### 动态股票技术数据

每个详细板块先从成份快照中过滤合格主板100元以下股票，再按流动性和强度选出最多8只短名单。所有板块短名单全局去重后，最多加载48只股票的日线和60分钟数据；同一股票只抓取一次。使用现有`load_stock`和`analyze_stock`生成趋势、量价、形态、价位和风险收益比。

## 板块评分模型

每个板块满分100分：

1. 当日涨幅及相对大盘强度：20分。
2. 5日和20日趋势持续性：20分。
3. 成交额及相对20日成交额：20分。
4. 上涨家数、下跌家数和涨停数：15分。
5. 龙头强度与板块内部梯队：15分。
6. 催化与风险代理：10分。

催化与风险维度优先使用可验证事件数据。没有可靠事件数据时，以5分中性基准开始，根据5日/20日趋势、广度、放量滞涨和高位脉冲风险进行加减分，并明确标记为“量价风险代理”，不得写成已核验新闻催化。

板块评分不得因单日大涨直接拉满。单日涨幅超过5%但上涨家数占比低于45%、量能异常放大后收弱，或板块内部只有一只股票拉动时，必须扣除风险分。

## 重点板块选择

- `top_boards`：行业和概念板块合并后，按板块综合评分取前5名。
- `rising_boards`：与上一有效交易日同类型排名比较，取排名提升最多且提升超过2位的前2名。
- 详细板块为两组去重后的并集，最多7个。
- `weak_boards`：综合评分最低的3个板块，仅作退潮风险提示，不生成强制2+2。
- 固定重点概念无论是否进入Top5，都在概念简表中保留；未进入详细板块时不强制生成2+2。

## 2+2角色选择

同一板块四个角色必须使用不同股票；不足时保留空缺并说明原因。

### 资金容量龙头

在合格候选中综合考察成交额、流通市值、日线/周线趋势和数据置信度。成交额权重最高，优先选择能够承载主流资金的标的。

### 弹性龙头

综合考察当日相对强度、换手率、60分钟趋势、放量突破和板块内排名。高位一字板、流动性不足或明显顶背离股票不得入选。

### 缩量回踩潜力股

必须具备可用价位计划；日线至少为偏多震荡，优先选择出现“缩量回踩”、收盘位于或接近回踩区、相对20日均量不高于1.05倍、60分钟不处于强势空头的股票。

### 放量突破潜力股

必须具备可用突破触发价；收盘距突破触发价不超过4%，日线至少为偏多震荡，60分钟不处于强势空头，优先选择相对量能改善但尚未连续加速的股票。

## 结构化输出

快照升级为`schema_version: 2`，新增：

```json
{
  "sectors": {
    "industry_ranking": [],
    "concept_ranking": [],
    "focus_concepts": [],
    "top_boards": [],
    "rising_boards": [],
    "weak_boards": [],
    "detailed_boards": [],
    "dynamic_candidates": [],
    "comparison": {},
    "source_status": []
  }
}
```

每个`detailed_boards`元素包含板块类型、代码、名称、评分、当日/5日/20日表现、成交额、相对量能、广度、涨停数、数据置信度以及四个角色。每个角色包含股票代码、名称、收盘价、涨跌幅、技术趋势、关键价位、入选理由和“是否只适合观察”。

## 历史比较

每日历史状态增加板块摘要：

- 新进入/退出板块Top5。
- 板块排名变化超过2位。
- 板块评分变化达到5分。
- 2+2角色股票发生变化。
- 重点概念由强转弱或由弱转强。

同日二次运行仍沿用“更完整结果优先”规则。板块数据完整度作为同日保留判断的次级条件：固定股票有效数相同后，优先保留具有更多有效板块历史、更多完整2+2角色的运行。

## 报告顺序

1. 市场环境。
2. 行业板块完整排名。
3. 重点概念板块排名。
4. 强势板块Top5、排名提升最快Top2和退潮板块Top3。
5. 每个详细板块的2+2。
6. 固定17只股票完整排名。
7. 固定池Top5重点分析。
8. 动态候选关键买点与条件。
9. 与上一交易日的板块及个股变化。
10. 最终只给：最值得等待回踩的板块和股票、最值得等待突破确认的板块和股票、当前最不适合追涨的板块和股票。

## 错误处理

- 板块接口失败不得中止固定17只股票复盘。
- 概念板块数据缺失时明确显示缺失来源和截止时间，不用固定池代理替代。
- 单个板块成份接口失败只影响该板块2+2。
- 单只动态候选行情失败时继续分析其他候选。
- 无合格股票时输出“无足够的沪深主板100元以下合格标的”，不强行补足。

## 性能边界

- 行业与概念列表各抓取一次。
- 只为候选详细板块抓取历史和成份。
- 每板块最多8只短名单，全局最多48只动态股票。
- 动态股票使用线程池并按代码去重。
- 生产工作流总超时继续控制在45分钟以内。

## 验收标准

1. 固定fixture运行仍输出17只股票和5只固定Top5。
2. 快照存在`sectors`且行业排名非空、重点概念齐全。
3. 详细板块最多7个，每个角色股票满足主板、100元以下、非ST和流动性规则。
4. 同一板块角色不重复；不足4只时保留空缺。
5. Markdown报告包含10个规定部分和板块2+2表。
6. 历史文件保存板块Top5与角色摘要。
7. 单元测试、Ruff、编译、固定17只端到端fixture全部通过。
